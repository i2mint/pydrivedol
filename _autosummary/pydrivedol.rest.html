pydrivedol.rest¶

Read a Drive folder over the plain Drive v3 REST API, and mirror it to disk.

No PyDrive2 and no OAuth flow: a folder shared “anyone with the link” needs only an API key; a private folder works the same way with an authorized session (for instance google.auth.transport.requests.AuthorizedSession) passed as session=. That session is the one seam between the two; everything else is shared.

>>> folder = PublicDriveFolder(folder_url, api_key=key)
>>> list(folder)
['intro.mp3', 'clips/a.mp4']
>>> folder.meta('clips/a.mp4')['size']
>>> report = sync_to_dir(folder, 'mirror/', include={'.mp4'})
>>> report.added, report.changed, report.unchanged

class pydrivedol.rest.PublicDriveFolder(url_or_id, *, api_key=None, session=None, recursive=True, include=None)[source]¶

Bases: Mapping

Read-only Mapping[path, bytes] over a Drive folder, through Drive v3 REST.

Keys are paths inside the folder ("sub/file.mp3"); Google-native documents (Docs, Sheets, …) have no bytes and are left out.

Parameters:

  • url_or_id (str) – the folder’s URL or its id.

  • api_key (Union[str, Callable[[], Optional[str]], None]) – a string, a zero-argument callable returning one, or None for env_api_key(). Never shown in repr. Not needed when session authenticates the requests.

  • session – a requests-compatible session; default a plain requests.Session. Pass an AuthorizedSession to read private folders.

  • recursive (bool) – descend into subfolders.

  • include – None, a suffix or collection of suffixes, or a predicate meta -> bool (meta holds name, mimeType, …).

pydrivedol.rest.sync_to_dir(folder, dest, *, include=None, index_name='.pydrivedol/index.json', prune=False, **folder_kwargs)[source]¶

Mirror a Drive folder into dest, downloading only what is new or changed.

An index (path -> md5) is kept in dest, so a re-run with nothing changed downloads nothing. A file is fetched when it is absent locally or its md5 differs from the indexed one. A file that fails to download is reported in SyncReport.failed and the rest carry on.

Parameters:

  • folder (Union[PublicDriveFolder, str]) – a PublicDriveFolder, or a folder URL/id (then built with folder_kwargs: api_key, session, recursive).

  • dest (Union[str, Path]) – the local directory (created if needed).

  • include – as for PublicDriveFolder; applied on top of the folder’s own.

  • index_name (str) – index file, relative to dest.

  • prune (bool) – also delete local files this mirror downloaded that are no longer in the folder. Narrowing include never prunes; an empty listing, or a change of recursive since the last run, refuses to prune.

Return type:

SyncReport
